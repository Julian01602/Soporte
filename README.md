## 🌲 ¿Qué es Soport?

**Soport** es una solución web desarrollada con **React** y **Supabase** diseñada para automatizar el ciclo completo de atención de soportes del SENA, optimizando el tiempo de respuesta y eliminando procesos manuales.

---

## ⚡ Stack Tecnológico

| Módulo | Tecnología | Descripción |
| :--- | :--- | :--- |
| **Frontend** | ![React](https://img.shields.io/badge/React-000000?style=flat-square&logo=react&logoColor=009944) | Interfaz moderna, rápida y reactiva |
| **Backend & DB** | ![Supabase](https://img.shields.io/badge/Supabase-000000?style=flat-square&logo=supabase&logoColor=009944) | Base de datos PostgreSQL y motor de autenticación |
## 🌲 Módulo Principal

- 🤖 **Automatización de Soportes:** Recepción, procesamiento e ingesta automática de solicitudes y tickets sin intervención manual.
